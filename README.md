# Simple Calculator 🧮

A simple and responsive calculator built with **HTML, CSS, and vanilla JavaScript**.

This project was created as a JavaScript practice project to understand DOM manipulation, functions, input values, and basic arithmetic operations.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* Responsive design
* Clean and simple user interface
* User input handling with JavaScript
* Result displayed dynamically on the page

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📚 What I Learned

While building this project, I practiced:

* `document.getElementById()`
* `.value`
* `Number()`
* JavaScript functions
* Variables
* Basic arithmetic operators
* `.innerText`
* `onclick` events
* CSS responsive design
* Basic Git and GitHub workflow

3. Open `index.html` in your browser.
